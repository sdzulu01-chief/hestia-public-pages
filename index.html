Hestia Calendar DEV

Hestia Calendar DEV is a private household calendar application developed as part of Project Hestia by Hermosillo Infrastructure Group.

Its Today view helps approved household members see the day's shared schedule: event titles, start and end times, and all-day events in Pacific time.

Read-only access to one approved calendar

A household administrator authorizes Google access. Hestia reads only the approved Family calendar. It does not create, edit, delete or RSVP to events, send reminders, or control household equipment.

The Google permission is https://www.googleapis.com/auth/calendar.events.readonly. Google describes it as viewing events on all your calendars. Hestia itself restricts requests to the one approved Family calendar; this application restriction does not narrow the Google permission.

Private household access

The schedule is available inside the authenticated household application. This public information page does not display the household's calendar or provide access to the household application.

The regular Hestia calendar release is being prepared. This page does not announce deployment or approval by Google.
